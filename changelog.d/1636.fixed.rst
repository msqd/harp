Rules now match ``/api//admin``, ``/admin;x=1``, ``/admin/`` and ``/admin%2Fusers`` like the clean path (empty segments, ``;`` parameters and the trailing slash are dropped, ``%2F`` also matches as ``/``), so deny rules hold for the variants upstreams normalise; the forwarded path is unchanged. Known limits: double-encoded escapes, ``%3B``, backslashes and upstream-specific rewriting are not normalised, ``on_remote_*`` levels still match the raw path, and a pattern with a trailing slash no longer matches.

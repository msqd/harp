A response carrying only an ``ETag`` or ``Last-Modified``, with no ``Cache-Control`` or ``Expires``, is retained again and revalidated on each use: a ``304`` serves the stored body instead of a full refetch, and it is never served without the origin confirming it (``allow_heuristics`` still opts into heuristic freshness). It is retained only when its request carried no credential header (``Authorization``, ``Proxy-Authorization``, ``Cookie`` and any name a rule declares) and its response sets no cookie. Limits: a credential sent under a header no rule declares is invisible to the cache, declare it; a response with ``Cache-Control: no-cache`` is still not retained; ``allow_stale: true`` serves such a response stale like any other; entries stored under ``allow_heuristics: true`` and read after turning it off are revalidated.

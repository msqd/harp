Credentials are redacted before storage: ``Authorization``, ``Proxy-Authorization``, ``Cookie`` and ``Set-Cookie`` values are stored as ``REDACTED`` by default, rules name more headers and query parameters through ``transaction.redaction``, and the cache no longer stores responses that vary on, carry or were requested with a redacted value, nor those of a transaction marked ``skip-request-storage`` or ``skip-response-storage``. Only new traffic is affected.

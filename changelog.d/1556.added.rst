Proxy: a remote endpoint changing state is now an event. A manual change through ``PUT /api/system/proxy`` is audited as ``proxy.remote.state_changed`` (with the Editor as actor, and ``denied`` for a refused attempt), and restores the previous state if the commit fails. A change made by the breaker or the liveness is logged on ``harp.events`` with no actor, once per real transition. The dashboard now depends on the ``audit`` application.

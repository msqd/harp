Default stack is now ``hypercorn`` on ``uvloop`` (``--server hypercorn+uvloop``, ``uvloop`` is a core dependency except on Windows, where the default stays ``hypercorn``) with the aiohttp upstream transport (``http_client.transport.type: harp_apps.http_client.aiohttp_transport.AiohttpTransport``). The aiohttp transport refuses at startup what it cannot honour (``retries`` above 0, ``verify`` as a CA path, ``limits.max_keepalive_connections``, HTTP/2); to restore the previous defaults use ``--server hypercorn`` (or ``HARP_SERVER=hypercorn``) and ``http_client.transport.type: httpx.AsyncHTTPTransport``.

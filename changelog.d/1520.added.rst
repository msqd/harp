The dashboard signs people in with a password and a server-side session (``auth_identities``, ``auth_sessions``), with a sign-out and a sign-out everywhere. Failed sign-ins, Basic included, are refused with ``429`` and ``Retry-After`` per address, per account and per address and account, so that nobody can lock out somebody on another address; ``dashboard.trusted_proxies`` names the reverse proxies whose ``X-Forwarded-For`` is believed. The open mode (``dashboard.auth.type: none``) and the password generated at each start are gone: while no administrator exists, HARP logs a setup link (single use, 72 hours) that creates the first one, and ``auth:create-account`` now sets a password.

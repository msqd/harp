The dashboard signs people in with a password and a server-side session (``auth_identities``, ``auth_sessions``), with a sign-out and a sign-out everywhere. The open mode (``dashboard.auth.type: none``) and the password generated at each start are gone: while no administrator exists, HARP logs a setup link (single use, 72 hours) that creates the first one, and ``auth:create-account`` now sets a password.

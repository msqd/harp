Changelog fragments
===================

One file per pull request, named ``<issue>.<type>.rst`` (or ``+<slug>.<type>.rst`` without an
issue) and holding a one-line entry. Types: ``important``, ``added``, ``changed``, ``fixed``,
``security``, ``removed``, and ``tooling`` (CI, test and build tooling: kept out of the release
notes). See ``docs/contribute/release/changelog.rst``.

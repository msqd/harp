Package metadata now declares license, classifiers and project links. Unused dependencies (``dataclasses-json``, ``sqlalchemy-utils``, ``aiohttp``, ``slack-sdk``) are gone, ``asgi-tools`` and ``colorama`` are development-only, and ``sentry-sdk`` moves to the ``sentry`` extra (``pip install harp-proxy[sentry]``; the Docker images include it). Slack notifications are sent with ``httpx``.

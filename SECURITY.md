# Security policy

## Supported versions

The latest two version lines (stable and oldstable, see
[branching](https://github.com/msqd/harp/blob/main/docs/contribute/branching.rst)) receive security fixes,
as patch releases.

## Reporting a vulnerability

Do not open a public issue or pull request.

Use the repository's private vulnerability reporting:
[report a vulnerability](https://github.com/msqd/harp/security/advisories/new).

We aim to acknowledge reports promptly and keep reporters informed of progress. Fixes ship as patch
releases, published together with the advisory.

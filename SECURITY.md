# Security policy

## Supported versions

Only the latest version line receives security fixes, as patch releases (see
[branching](https://github.com/msqd/harp/blob/main/docs/contribute/branching.rst)).

## Reporting a vulnerability

Do not open a public issue or pull request.

Use the repository's private vulnerability reporting:
[report a vulnerability](https://github.com/msqd/harp/security/advisories/new).

We acknowledge a report within 3 working days and give a first assessment within 7 days. Fixes
ship as patch releases, published together with the advisory.

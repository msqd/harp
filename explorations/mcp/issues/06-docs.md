# docs: connecting an MCP client to HARP

**Problem**

Operators and developers need to know how to turn the server on and plug an agent into it.

**Acceptance criteria**

- An apps page for `mcp`: the extra, enabling the application, every setting and its default, what each tool returns, the role each tool needs, and that bodies stay out unless `mcp.bodies` is on, with why (they leave for the LLM provider).
- How to create a token and configure a client with it, with one example for a common MCP client.

**Out of scope**

Client-specific troubleshooting.
